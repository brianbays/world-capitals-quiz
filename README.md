# World Geography Quiz

Live at https://brianbays.com/world-capitals-quiz/ through this repository's GitHub Pages project site.

This project site's route takes precedence over the same folder in brianbays.github.io. Publish quiz changes here. The main portfolio repository contains the Playground landing page and its footer link.

- index.html: self-contained country/capital quiz and map.
- answer-key.html: study key.
- countries.json and capital-locations.json: data and coordinate provenance.
- License files retain data attribution.

Territories default off (197 countries); checking Include territories enables all 245 entries. The map has capital dots, interactive controls and close-up insets for small locations.

To update manually, upload replacement quiz files to THIS repository's root and commit to main. Keep the folder structure in brianbays.github.io separate: its published root is site/.
